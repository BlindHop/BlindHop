# Trustless Guarantees

BlindHop is designed to be **trustless at every stage** of the pipeline. No trusted setup, no trusted hardware, no trusted third parties.

## Trust Elimination Table

| Stage | Traditional Trust | BlindHop Elimination |
|---|---|---|
| **Mixnode identity** | "Trust that the mixnode is a real validator" | ZK eligibility proof — proves membership without revealing identity |
| **Packet relay** | "Trust that the mixnode forwarded correctly" | ZK relay proof — cryptographic proof of correct decryption + forwarding |
| **Cover traffic** | "Trust that mixnodes generate cover traffic" | ZK cover compliance proof — verified on-chain, non-compliance = slashing |
| **Transaction validity** | "Trust that the extrinsic is well-formed" | ZK tx validity proof — generated by client, verified by exit node |
| **Multi-hop integrity** | "Trust the entire path was honest" | Recursive Binary Proof Tree — single root proof attests to all hops |
| **On-chain verification** | "Trust the runtime to verify correctly" | PolkaVM JIT — same verifier code runs on-chain and off-chain |
| **Proof availability** | "Trust that proofs are stored" | Kademlia DHT — self-authenticating (Blake3 hash committed on-chain) |
| **Standalone operators** | "Trust non-validator mixnodes" | Staking bond + same ZK eligibility proof as validators |
| **Trusted setup** | "Trust the ceremony participants" | **None needed** — Stwo Circle STARKs are fully transparent |
| **Quantum resistance** | "Trust that crypto won't be broken" | Stwo is hash-based (post-quantum secure) |

## Verification Flow

Every claim in the system is backed by a cryptographic proof that can be independently verified:

```
Mixnode claims eligibility → verified by ZK eligibility proof
Mixnode claims correct relay → verified by ZK relay proof
Mixnode claims cover compliance → verified by ZK cover compliance proof
Aggregator claims valid tree → verified by recursive Stwo verification
On-chain checkpoint claims validity → verified by Stwo verifier contract
```

No component requires "trust me" — everything is "verify me".
